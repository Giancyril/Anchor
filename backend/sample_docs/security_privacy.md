# Security and Privacy Policy

## Data Encryption
All data at rest is encrypted using AES-256. All data in transit is encrypted using TLS 1.3. Database backups are encrypted and stored in geographically redundant locations.

## Authentication
We support email/password login with bcrypt password hashing, Single Sign-On (SSO) via SAML 2.0, and Multi-Factor Authentication (MFA) via TOTP apps such as Authy or Google Authenticator. MFA is mandatory for Admin accounts.

## Data Retention
Customer data is retained for the duration of the active subscription plus 90 days after cancellation, after which it is permanently deleted from all systems including backups.

## GDPR Compliance
We are fully GDPR compliant. EU customers can submit a Subject Access Request (SAR) via the Privacy Center in their account settings. We respond to all SARs within 30 days.

## Security Incident Response
In the event of a security breach, we will notify affected customers within 72 hours via email and publish a detailed post-mortem on our status page.
